# 🎮 Tic Tac Toe Game

A highly interactive, classic web-based Tic Tac Toe experience crafted completely from scratch.

---

## ✨ Features & Overview
This project brings the timeless game of Tic Tac Toe to the browser with a focus on clean design and immediate playability. 

* **Classic Gameplay:** Standard 3x3 grid perfectly balanced for two local players.
* **Interactive UI:** A distraction-free, minimalist, and responsive web interface.
* **Audio Feedback:** Integrated click sound effects for a highly engaging user experience.
* **Zero Setup:** A purely front-end architecture that requires no server environment to run.

## 🚀 Quick Start Guide
Get the game running on your local machine in just a few seconds:

1. Download or clone this repository directly to your local machine.
2. Open the downloaded project folder.
3. Double-click the `tic toi.html` file to launch it in your default web browser.
4. Start playing immediately!

| Technology | Purpose |
