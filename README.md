# 🎮 Tic Tac Toe Game

A classic, interactive web-based Tic Tac Toe game built completely from scratch. 

## ✨ Features
* **Classic Gameplay:** Standard 3x3 grid for two players.
* **Interactive UI:** Clean, simple, and responsive web interface.
* **Audio Feedback:** Includes click sound effects for an engaging user experience.

## 🚀 How to Run
Since this is a front-end only project, no installation or server environment is required!
1. Download or clone this repository to your local machine.
2. Navigate to the project folder.
3. Double-click the `tic toi.html` file to open it in your default web browser.
4. Start playing!

## 🛠️ Technologies Used
* **HTML5:** For the structure of the game board.
* **CSS3:** For styling and visual layout.
* **JavaScript:** For the game logic and sound integration.
